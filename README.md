# SiteForge AI

Первая frontend-версия AI-конструктора сайтов.

## Запуск
1. Открой `index.html` в браузере.
2. В блоке Generator напиши идею сайта.
3. Нажми «Сгенерировать».

## Что уже есть
- адаптивный дизайн;
- тёмная тема и градиенты;
- анимации появления;
- AI-style генератор макета;
- готовые шаблоны;
- тарифы;
- интерактивные кнопки;
- мобильная версия.

## Следующий этап
Для настоящего продукта можно подключить backend, базу данных, авторизацию, оплату, AI API, сохранение проектов и реальный экспорт/публикацию сайтов.
